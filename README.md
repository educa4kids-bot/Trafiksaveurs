# Trafik Saveurs — تطبيق سطح المكتب (ويندوز)

## البناء والتثبيت على سطح المكتب (مع الأيقونة)
1. ضع ملفات النظام (index.html …) داخل مجلد `web`.
2. شغّل `build.bat` ← ينتج `dist\TrafikSaveurs.exe` بأيقونة `app.ico`.
3. شغّل `install.bat` ← ينسخ البرنامج إلى `%LOCALAPPDATA%\Programs\TrafikSaveurs` وينشئ اختصاراً على سطح المكتب وقائمة ابدأ.
(إن ظهرت الأيقونة القديمة فهذا من ذاكرة الأيقونات في ويندوز؛ أعد تشغيل المستكشف.)

## التشغيل المباشر (للتجربة)
1. ثبّت Python 3.9+ (يُفضّل 3.11) مع تفعيل "Add to PATH".
2. انقر مرتين على `run.bat`.

## إنشاء ملف EXE واحد قابل للنسخ لأي جهاز
- على ويندوز: شغّل `build.bat` ← تجده في `dist\TrafikSaveurs.exe` (لا يحتاج Python على الأجهزة الأخرى).
- أو ارفع هذا المجلد إلى GitHub وسيبني Actions الملف تلقائياً (تبويب Actions ← Artifacts).

## أين تُحفظ البيانات؟
- داخل المتصفح المدمج: `%APPDATA%\TrafikSaveurs\webview`
- نسخة احتياطية تلقائية بعد كل تعديل: `%APPDATA%\TrafikSaveurs\data.json`
- نسخ يومية (آخر 30 يوماً): `%APPDATA%\TrafikSaveurs\backups`
- إن فُقدت البيانات يعرض البرنامج استرجاع آخر نسخة تلقائياً.
